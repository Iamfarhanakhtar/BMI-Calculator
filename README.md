# 🧮 BMI Calculator

A simple and interactive **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**.  
It allows users to input their height and weight, calculates their BMI, and displays the health category instantly.

---

## 🚀 Live Demo
🔗 [Click here to view the project](https://iamfarhanakhtar.github.io/BMI-Calculator/)

---

## 💡 Features
- Input height (in cm) and weight (in kg)
- Calculates BMI instantly on form submit
- Displays BMI value and health category
- Validates inputs and shows helpful error messages
- Clean, minimal UI with gradient backgrounds
- Interactive hover effects and result highlighting

---

## 🧠 Technologies Used
- **HTML5** for structure  
- **CSS3** for styling and layout  
- **JavaScript (Vanilla JS)** for calculation logic



## 🧩 How to Use
1. Enter your **height** in centimeters.  
2. Enter your **weight** in kilograms.  
3. Click on the **Calculate** button.  
4. Instantly view your BMI and weight category:
   - Underweight → BMI < 18.6  
   - Normal → 18.6 ≤ BMI < 24.9  
   - Overweight → 24.9 ≤ BMI < 30  
   - Obese → BMI ≥ 30
